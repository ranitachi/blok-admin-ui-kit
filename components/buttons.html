    UI Kit · Komponen

    Tombol

    Tombol tegas dengan border 2px dan bayangan keras. Setiap contoh di bawah bisa dicoba langsung dan kodenya bisa disalin.

    Lanjut ke kartu Lihat split button

    Varian tombol

    Enam gaya dasar. Pakai primary hitam untuk aksi utama (satu per area), kuning untuk ajakan menonjol, outline/ghost untuk aksi sekunder, dan destructive hanya untuk aksi yang menghapus.

  <figure class="nb-specimen">
    <button class="nb-btn" type="button">Simpan perubahan</button>
    <figcaption>.nb-btn · primary</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn nb-btn--yellow" type="button"><svg class="nb-icon" aria-hidden="true"><use href="#i-plus"></use></svg>Tambah aset</button>
    <figcaption>.nb-btn--yellow</figcaption>
  </figure>
  <figure class="nb-specimen">

    <figcaption>.nb-btn--outline</figcaption>
  </figure>
  <figure class="nb-specimen">

    <figcaption>.nb-btn--ghost</figcaption>

    State

    Hover menekan tombol 2px (bayangan mengecil). Active/pressed menempel penuh. Disabled memakai atribut disabled, bukan hanya warna. Klik tombol Loading untuk melihat aria-busy selama 1,5 detik.

    HTML 
    <div class="nb-specimens">
  <figure class="nb-specimen">
    <button class="nb-btn" type="button">Normal</button>
    <figcaption>default</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn nb-btn--yellow" type="button" data-loading-demo>Simpan (klik)</button>
    <figcaption>.is-loading + aria-busy</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn" type="button" disabled>Nonaktif</button>
    <figcaption>[disabled]</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn nb-btn--outline is-active" type="button">Aktif</button>
    <figcaption>.is-active</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn nb-btn--outline is-focus" type="button">Fokus</button>
    <figcaption>:focus-visible</figcaption>
  </figure>
  <figure class="nb-specimen">
    <button class="nb-btn nb-btn--outline" type="button" aria-pressed="false" data-toggle-pressed><svg class="nb-icon nb-icon--sm" aria-hidden="true"><use href="#i-pin"></use></svg>Sematkan</button>
    <figcaption>toggle · aria-pressed</figcaption>
  </figure>
</div>

    Split button

    Aksi utama di kiri, aksi alternatif di menu kanan. Menu mendukung panah atas/bawah, Home/End, dan Esc mengembalikan fokus ke pemicu.

  <button class="nb-btn nb-btn--yellow" type="button" data-toast="Laporan diekspor (demo)" data-toast-message="Format PDF. Tidak ada file yang benar-benar dibuat." data-toast-type="success"><svg class="nb-icon nb-icon--sm" aria-hidden="true"><use href="#i-download"></use></svg>Ekspor PDF</button>
  <div class="nb-dropdown" data-dropdown>
    <button class="nb-btn nb-btn--yellow nb-btn--caret" type="button" data-dropdown-trigger aria-haspopup="menu" aria-expanded="false" aria-controls="split-menu" aria-label="Format ekspor lainnya"><svg class="nb-icon nb-icon--sm" aria-hidden="true"><use href="#i-chevron-down"></use></svg></button>
    <div class="nb-menu" id="split-menu" role="menu" aria-label="Format ekspor" hidden>
      <button class="nb-menu__item" type="button" role="menuitem" data-toast="Ekspor CSV (demo)" data-toast-message="Tidak ada file yang dibuat."><svg class="nb-icon nb-icon--sm" aria-hidden="true"><use href="#i-file"></use></svg>Ekspor CSV</button>
      <button class="nb-menu__item" type="button" role="menuitem" data-toast="Ekspor Excel (demo)" data-toast-message="Tidak ada file yang dibuat."><svg class="nb-icon nb-icon--sm" aria-hidden="true"><use href="#i-layers"></use></svg>Ekspor Excel</button>
