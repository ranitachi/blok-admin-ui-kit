    Input teks, email, angka & textarea

    Setiap kontrol punya label yang terhubung, teks bantuan lewat aria-describedby, dan state disabled/read-only yang tetap terbaca. Penanda * disertai teks "wajib" di deskripsi formulir.

    Gunakan nama yang mudah dicari.

    unit
    Rp

    Kata sandi dengan tombol tampilkan

    Tombol mata adalah button dengan aria-pressed dan label yang berubah (Tampilkan/Sembunyikan). Kolom konfirmasi divalidasi dengan data-match.

    Tanggal, waktu, rentang & slider

    Dropzone unggah file

    Input file asli tetap ada (dapat difokus dan dipakai keyboard) di atas area seret-lepas. File di atas 2 MB ditolak; progres unggah hanya simulasi — tidak ada yang dikirim.

    PDF, PNG, JPG atau CSV · maks. 2 MB per file

  <input id="f-file" type="file" multiple accept=".pdf,.png,.jpg,.jpeg,.csv" aria-describedby="f-file-help">

      Validasi & ringkasan error
