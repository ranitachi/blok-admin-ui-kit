    Dokumentasi

    Mulai di sini

    Panduan singkat memakai dan memperluas BLOK Admin UI Kit.

    Struktur folder

    Seluruh situs adalah berkas statis. Tidak ada build, bundler, maupun backend.

    neo-brutal-html/
  index.html                  katalog halaman (diisi tools/sync-shell.py)
  dashboard*.html             3 dashboard (ringkasan, analitik, operasional)
  assets/css/                 tokens, reset, layout, components, pages, responsive
  assets/js/                  icons, app, components, forms, tables, charts, data, records
  assets/js/pages/            satu berkas per halaman/kelompok halaman
  components/                 14 halaman demo komponen UI Kit
  pages/                      halaman bisnis (CRUD, operasional, laporan, dll.)
  auth/                       login, register, lupa & atur ulang kata sandi
  errors/                     403, 404, 500
  documentation/              halaman dokumentasi ini
  tools/sync-shell.py         sinkron sidebar/topbar/breadcrumb/katalog
  tools/qa/                   check-static.py, sweep.js

    Membuka atau menyajikan secara lokal

    Buka index.html langsung di browser, atau sajikan lewat server statis agar path relatif dan font berperilaku sama seperti di hosting:

    cd neo-brutal-html
python3 -m http.server 8000
# lalu buka http://localhost:8000/

    Font Google Fonts dimuat dari CDN. Tanpa koneksi, halaman memakai font sistem (fallback di tokens.css).

    Urutan CSS dan JS

    Urutan wajib sama di semua halaman. responsive.css dimuat paling akhir sehingga menimpa pages.css. Halaman di subfolder memakai awalan ../.

    <link rel="stylesheet" href="../assets/css/tokens.css">
<link rel="stylesheet" href="../assets/css/reset.css">
<link rel="stylesheet" href="../assets/css/layout.css">
<link rel="stylesheet" href="../assets/css/components.css">
<link rel="stylesheet" href="../assets/css/pages.css">
<link rel="stylesheet" href="../assets/css/responsive.css">

<script src="../assets/js/icons.js" defer></script>
<script src="../assets/js/app.js" defer></script>
<script src="../assets/js/components.js" defer></script>
<script src="../assets/js/forms.js" defer></script>
<!-- opsional, hanya bila halaman memakainya: -->
<script src="../assets/js/tables.js" defer></script>
<script src="../assets/js/charts.js" defer></script>
<script src="../assets/js/pages/nama-halaman.js" defer></script>

    Membuat halaman baru

    1. Salin halaman yang paling mirip, misalnya pages/help-center.html, lalu ubah <title> (harus unik), meta description, data-page, dan isi <main>.
    2. Daftarkan halaman di tuple PAGES pada tools/sync-shell.py: (key, path, label, kategori, ikon, fase, nav_parent).
    3. Jalankan python3 tools/sync-shell.py. Sidebar, topbar, breadcrumb, dan katalog di index.html terisi otomatis.
    4. CSS baru ditambahkan di akhir assets/css/pages.css; JS khusus halaman di assets/js/pages/. Jangan menduplikasi stylesheet per halaman.
    5. Periksa dengan tools/qa/check-static.py dan tools/qa/sweep.js.

    Menjalankan tools/sync-shell.py

    Skrip opsional (Python 3 standar) yang menulis ulang blok di antara penanda <!-- nb:sidebar -->, nb:topbar, nb:crumbs, serta nb:progress dan nb:catalog di index.html. Halaman yang file-nya belum ada tampil sebagai item "Segera", bukan tautan mati.

    python3 tools/sync-shell.py          # tulis perubahan
python3 tools/sync-shell.py --check  # hanya laporkan berkas yang berbeda

    Halaman auth dan error memakai layout mandiri tanpa marker, sehingga tidak disentuh skrip selain atribut data-page.

    Pemeriksaan kualitas

    Dua skrip di tools/qa/:

    python3 tools/qa/check-static.py            # tautan, id, kelas, judul ganda
CHROME_PATH=/path/ke/chrome node tools/qa/sweep.js   # 5 lebar, console, overflow

    sweep.js membutuhkan puppeteer-core dan server lokal yang sedang berjalan.

    Batasan demo statis

    • Tidak ada backend. Semua data fiktif; form auth adalah demo visual dan tidak menyimpan kata sandi.
    • Perubahan CRUD dan preferensi tampilan hanya bertahan selama tab terbuka (sessionStorage).
    • Tidak ada fetch ke server mana pun.
