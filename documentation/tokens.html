    Breakpoint

    Stylesheet di responsive.css memakai media query berikut (CSS custom property tidak bisa dipakai di media query, jadi nilainya tertulis langsung).

    Breakpoint
    KondisiPerilaku
    ≥ 1440pxLayar lebar: konten sampai --content-max
    ≤ 1279pxLayar sedang: topbar dan kolom grid dirapatkan
    ≤ 1023pxSidebar menjadi drawer; breadcrumb pindah ke konten
    ≤ 767pxPonsel: satu kolom, --gutter dan --topbar-h mengecil
    ≤ 374pxPonsel kecil (320–374px)
