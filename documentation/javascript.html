    Dokumentasi

    API JavaScript

    Vanilla JS tanpa framework. Semua yang tampil di sini diambil dari berkas di assets/js/.

    API global NB

    Semua modul menempel pada objek global window.NB.

    API global NB
    APIBerkasFungsi
    NB.ready(fn)app.jsJalankan fn setelah DOM siap (langsung bila sudah siap).
    NB.qs(sel, root?)app.jsPintasan querySelector.
    NB.qsa(sel, root?)app.jsquerySelectorAll sebagai Array.
    NB.escapeHtml(str)app.jsEscape & < > " ' sebelum disisipkan ke innerHTML.
    NB.storage.get/set(key, value)app.jsPembungkus localStorage yang aman bila storage diblokir.
    NB.display.get/set/clear/applyapp.jsPreferensi tampilan (density, textsize, motion) di sessionStorage; menulis atribut data-density, data-text, data-motion pada <html>.
    NB.focus.list(root) / NB.focus.trap(root)app.jsDaftar elemen fokusabel dan jebakan Tab.
    NB.isDesktop()app.jsTrue bila lebar viewport ≥ 1024px.
    NB.sidebarapp.jsKontrol sidebar (collapse desktop, drawer mobile).
    NB.toast({type, title, message, timeout})components.jsTampilkan toast; type: success | info | warning | danger.
    NB.modal.open(id, opener?) / NB.modal.close(id)components.jsBuka/tutup modal atau drawer; fokus kembali ke pemicu.
    NB.copyText(text)components.jsSalin teks ke clipboard.
    NB.forms.validate(root) / validateField(field) / reset(form)forms.jsValidasi dan reset form.

    NB.countUp(scope)charts.jsAnimasi hitung angka (data-count-to).

    NB.passwordScore(pw)pages/auth.jsSkor kekuatan kata sandi untuk meter.

    Event kustom

    Semua event bergelembung (bubbles: true).

    Event kustom
    EventBerkasKeterangan
    nb:valid-submitforms.jsForm valid disubmit. detail = {form, data: FormData}. Dengarkan ini, bukan submit.
    nb:form-resetforms.jsForm direset lewat NB.forms.reset.
    nb:modal-open / nb:modal-closecomponents.jsModal dibuka/ditutup (bubbles).
    nb:dismisscomponents.jsAlert ditutup.
    nb:toggle-groupcomponents.jsPilihan grup toggle berubah.

    Contoh kode

    <form id="form-contoh" data-validate novalidate>
  <label class="nb-label" for="nama">Nama</label>
  <input class="nb-input" id="nama" name="nama" required
         data-required-message="Nama wajib diisi.">
  <button class="nb-btn" type="submit">Simpan</button>
</form>
    NB.ready(function () {
  var form = NB.qs("#form-contoh");
  if (!form) return;
  form.addEventListener("nb:valid-submit", function (e) {
    var nama = e.detail.data.get("nama");
    NB.toast({ type: "success", title: "Tersimpan (demo)", message: nama });
    NB.modal.close("modal-contoh");
  });
});

    Batasan demo statis

    • Tanpa backend dan tanpa fetch. Semua data berasal dari data.js dan records.js.
    • sessionStorage dipakai untuk preferensi tampilan dan perubahan demo CRUD; hilang saat tab ditutup. localStorage hanya lewat NB.storage untuk preferensi UI.
    • Form auth tidak pernah menyimpan kata sandi.
    • Toast demo selalu bertanda "(demo)" dan tidak menjanjikan data tersimpan.
